# Symbol Vote — 模擬電子投票システム

候補者ごとに設定した大きなマークを見て、PC・タブレットから1票を投じる、学校・授業・イベント向けの模擬電子投票アプリです。外部サービスやログインを使わず、すべてのデータをブラウザの `localStorage` に保存します。

## インド選挙との対応関係

インドのLok Sabha選挙で使われるEVMとElection Symbolの考え方を参考にしています。実際の専用EVMの代わりにPC・タブレットを使い、候補者名に対応したマークを選んで投票する体験へ簡略化しています。当選判定はFirst-Past-The-Post方式（最多得票）です。同票時は自動決定しません。本アプリはElection Commission of Indiaの公式システムではありません。

## 実装機能

- 選挙名・説明・候補者数の設定
- 候補者名、説明、重複不可のマーク設定
- タブレット優先の大きな投票カードと確認ダイアログ
- 1投票セッションにつき1票、二重クリック防止
- 係員による「次の投票者」への切り替え
- `SETUP / READY / POLLING / PAUSED / CLOSED / COUNTED` の状態管理
- 投票中は総投票人数だけ表示し、候補者別得票を秘匿
- 開票後の順位、得票数、得票率、当選・同票表示
- 確認付きの全データ削除
- リロード後も選挙・候補者・投票・状態を保持

## 主なファイル構成

```text
app/                     各画面（setup, candidates, vote, admin, results 等）
components/election/     投票・候補者・結果のUI
components/admin/        管理操作UI
lib/election/            保存、投票制御、純粋な開票ロジック
types/election.ts        Election / Candidate / Vote / Session 型
```

## 投票方法

1. `/setup` で選挙を作成し、候補者とマークを登録します。
2. `/admin` で「選挙を開始」を押します。
3. `/vote` でマークを選択し、確認画面で投票を確定します。
4. 完了画面で5秒後に「次の投票者」を押します。票は保持され、選択状態だけが初期化されます。

## 管理者操作

`/admin` から投票受付の開始・一時停止・再開・終了・開票ができます。候補者別得票数は `COUNTED` になるまで表示されません。「すべての選挙データを削除」は確認画面を経て実行されます。

## テスト

`npm test` で投票先だけへの加算、同一セッションの二重投票防止、状態別投票可否、最多得票、同票を検証します。確認ダイアログで「戻る」は `castVote` を呼ばない設計で、票は記録されません。開票前の `/results` は結果カード自体を描画しません。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。本番ビルドは `npm run build`、テストは `npm test` です。
